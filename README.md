# Neon Brawl — CinemaX Fighting
Game fighting 2D satu lawan satu: pukul 👊, tendang 🦵, blok 🛡, lompat ▲ (serangan udara), dan Gelombang Neon 🔥 (butuh energi ≥ 50%, terisi saat memukul/dipukul).
Menangkan 2 dari 3 ronde. Mode: 1 Pemain vs CPU (Mudah/Normal/Sulit) atau 2 Pemain di satu keyboard.

**Android:** tombol sentuh di layar (multi-touch) · ⛶ layar penuh (kunci landscape bila didukung) · layar tetap menyala · getar saat terkena · jeda otomatis saat ditinggalkan.
Untuk tampilan tanpa bilah browser: Chrome ⋮ → "Tambahkan ke layar utama". Buka lewat hosting statis (mis. GitHub Pages), bukan dari file manager HP. iPhone Safari tidak mendukung Fullscreen API.
**Desktop:** P1 A/D/W/S + J/K/L · P2 panah + , . / · F layar penuh · P jeda · M suara.

Keamanan: CSP ketat, tanpa innerHTML/eval/jaringan; data hanya jumlah kemenangan di localStorage (sisi klien). Uji: `node tests/test.js`.
